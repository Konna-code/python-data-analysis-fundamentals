# 🛒 Python Project: Instacart Sales & Customer Segmentation Analysis

## 📘 Project Overview

Instacart is a successful **online grocery store** operating via a mobile app. While the company already enjoys strong sales, it seeks to uncover deeper insights into **sales patterns** and **customer behavior**.

As a data analyst, your task is to perform an **initial exploratory data analysis (EDA)** to derive actionable insights. These insights will support the company in developing **targeted marketing strategies** and improving their understanding of different customer segments.

---

## 🎯 Key Business Questions

1. What are the **busiest days and times** for orders?
2. When do customers **spend the most money**?
3. Can products be grouped into **simplified price ranges** for marketing?
4. Which **product departments** have the highest order frequency?
5. How do **different types of customers** behave? Consider:
   - Brand loyalty
   - Region
   - Age and family status
   - Income levels
   - Order frequency, basket size, and preferred product types

---

## 📊 Data Summary

Instacart has provided a collection of **open-source datasets** containing information on products, orders, departments, and customer demographics. All datasets share **common identifiers** to enable merging and cross-referencing.

---

## ✅ Project Tasks

### 1. Environment Setup
- Install **Anaconda**
- Launch **Jupyter Notebook**
- Create project folder and install required libraries

### 2. Python & Jupyter Fundamentals
- Create and organize notebooks
- Practice with basic Python data types

### 3. Data Loading & Exploration
- Import data using **pandas**
- Conduct basic **descriptive statistics** and inspection

### 4. Data Wrangling & Subsetting
- Convert data types and rename columns
- Use **data dictionaries** for interpretation
- Subset data based on various conditions
- Explore variable frequency and user behavior

### 5. Data Consistency Checks
- Address mixed data types
- Handle **missing values** and **duplicates**

### 6. Combining & Exporting Data
- Merge dataframes using keys
- Analyze merge results
- Export cleaned data as a **pickle file**

### 7. Deriving New Variables
- Use conditional logic (`if`, `loc()`, functions, loops) to create:
  - **Flags** (e.g., loyalty levels)
  - **Profile columns** for segmentation

### 8. Grouping & Aggregating
- Use `groupby()` to create aggregated summaries
- Compare customer groups by spending and order habits

### 9. Data Visualization
- Create charts using **matplotlib** and **seaborn**:
  - Histograms
  - Bar plots
  - Line charts
  - Scatter plots

### 10. Reporting & Recommendations
- Summarize findings and customer profiles
- Create an Excel report of insights
- Recommend marketing strategies based on analysis
